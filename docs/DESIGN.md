# SkillLens design

## Main screen

The single screen provides a PDF uploader, job-description text area, Analyze match action, summary score, matched skills, missing skills, evidence snippets, and Delete uploaded data and results action.

## Design principles

- Show evidence beside every match and gap.
- Describe the score as skill overlap, not a hiring decision.
- Use text labels for matched and missing sections; do not rely on color alone.
- Give clear upload, PDF, loading, and unsupported-skill feedback.
- Use Streamlit native accessible controls and render resume evidence as plain text.
